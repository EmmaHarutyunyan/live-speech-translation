# Chat sessions index

The brief requires every Claude Cowork session used for this project to be exported in full and unedited,
each as its own Markdown (.md) file in this folder. The original sessions must stay available in the app
for the interview — never delete or edit any session.

## Rules
- One row per session, added when the session starts.
- File name pattern: `NN-short-topic.md` (e.g. `01-planning-and-setup.md`).
- Exported files are never edited by hand. If the app's export is not Markdown, the raw export is kept
  as well and the conversion is done by a script that copies the text unchanged.
- Before submission: every row has status "exported" and the file exists.
